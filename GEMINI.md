# APYarchives.com

## Project Overview

APYarchives.com is a Next.js + React website designed to track and display the historical annual percentage yields (APYs) of popular high-yield savings accounts. The site will visualize APY trends over time with interactive charts and present a curated list of accounts to help users compare performance.

## Purpose

- Collect and surface historical APY data for top high-yield savings accounts.
- Make APY trends easy to compare with visual charts.
- Provide a clean, modern layout for fast decision-making.
- Prepare the application for future database integration and deployment.

## Initial Scope

The first layout will include:

- A top section with a graph showing APY history for multiple accounts over time.
- A bottom section with a list of tracked savings accounts.
- A responsive design optimized for desktop and mobile viewing.

## Technology Stack

- Next.js for the application framework and routing.
- React for UI components.
- Styled components, CSS modules, or Tailwind CSS for styling (TBD).
- Charting library to render APY comparison graphs (TBD).

## Future Plans

- Add Supabase integration for persistent APY history storage.
- Build a backend API to fetch and update account APY records.
- Deploy the site to a production hosting environment.
- Expand account coverage and support user-customizable watchlists.

## Naming

The website will be branded as `APYarchives.com`, reflecting its role as a historical archive for savings account APYs.
